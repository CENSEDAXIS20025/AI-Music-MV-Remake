# THE INDEX OF YOU
### Mili《world.search (you) ;》— 亮色（纸张）版 · 一部关于**语义检索**的音乐短片

一台机器想把「你」找出来。它的办法是——**假设你变成别的东西，然后描述那个东西**。
桌子、茄子、猫、牛排、花、人。它一直在搜，但你要么不完全符合，"somehow you can't stop
transforming"。最后它终于想起那个词：**Lo-o-o-ove**。

全片是**一叠索引卡**。两个统一装置：

1. **查询栏**（顶部）——**当前歌词行就是搜索词**，右侧是实时命中数；
2. **索引轨**（底部）——1945 到 2026 的检索史，随歌一格一格点亮：Vannevar Bush 的 memex →
   倒排索引 → TF-IDF → BM25 → PageRank → word2vec → 注意力 → 向量数据库 → RAG → CLIP →
   长上下文 → 1,050,000 token。

> 与姊妹篇《world.execute (me) ;》（深色 CRT、关于**执行与服从**）是两部不同的片子：
> 那一部讲机器被造出来、被训练、被使用、被弃用；这一部讲机器**去找一个它说不清名字的东西**。
> 主题、色板、装置都不一样，各自独立。

## 视觉

**这是纸。** 亮色不是「深色画面调亮」，是印刷品：卡片、横格纸、索引标签、印章、红笔批注、
点阵打印纸、微缩胶片、档案抽屉。整部片子由引擎的纸主题管线统一处理（亮度反转 + 纸纤维颗粒 +
印刷套印偏差），所以段落内容按深色约定编写，成片自动变成墨与纸。

时代墨色随历史前进：比较的暖橙 → 索引的琥珀 → 目录的淡蓝 → 约束的青 → 模糊的紫 →
空等的品红 → facets 的蓝 → 多模态的橙棕 → 稀疏的金 → 人的白 → 神经检索的品红 →
typeahead 的青 → 词向量的玫红 → 语义地图的紫 → 重试的红 → 失去的灰 → 桶的金橙 →
tokens 的冰蓝 → 长上下文的绿 → 学会的青 → 快乐的暖金 → 未解的白。

## 本地运行

```bash
python -m http.server 8799
# 打开 http://127.0.0.1:8799/index.html
```

单文件版 `world.search(you).index.html` 不需要服务器，双击即可。

## 自检

```bash
node tools/check.mjs --url=http://127.0.0.1:8799/index.html --sections --outdir=out/check
```

渲染是确定性的：`window.__render(t)` 按给定时间画一帧，截图与实时播放所见一致。

## 打包

```bash
node tools/bundle.mjs     # -> world.search(you).index.html
```
